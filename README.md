# crime-rate-analysis-india
B.Sc Statistics Academic Project | 2024
Objective- To study the impact of socio-economic factors like Literacy Rate, Unemployment, and Population Density on Crime Rate across    Indian states using 10-year NCRB data.
Data Used -Source: National Crime Records Bureau (NCRB) + Census 2011, data.gov.in
   Period: 2012 to 2022
   Coverage: 28 States & 8 UTs of India
Methodology & Tools-Data Collection - Downloaded raw data from official government portal
       Data Cleaning- Used MS Excel to handle missing values, remove duplicates, format data
Statistical Analysis - 
      Correlation Analysis to find relationship between variables
      Multiple Linear Regression to identify significant factors
      ypothesis Testing for validation
Visualization-
      Created Pivot Tables, Bar Charts, Scatter Plots & Interactive Dashboard in Excel
Key Findings-
      Unemployment rate shows strong positive correlation (r = 0.72) with total cognizable crimes.
      States with higher literacy rate tend to have comparatively lower crime rates.
      Regression model explains 81% of variance in crime rate (R² = 0.81).
Skills Applied
      MS Excel, Data Cleaning, Statistical Analysis, Regression, Data Visualization, Report Writing, Public Data Handling
Project Status
Academic project completed as part of B.Sc curriculum. Currently enhancing the analysis by replicating it in Python for advanced modeling.
